# 🎓 Student Result Analysis  
A clean and insightful data-analysis project exploring how study habits, demographics, and parental education impact student performance.


---

## 📘 Overview

This project performs **Exploratory Data Analysis (EDA)** on student academic results to uncover patterns and insights related to:

- Weekly study hours  
- Gender differences  
- Parental education influence  
- Score distributions (Math, Reading, Writing)

The project includes **data cleaning**, **visualizations**, and **interpretation of trends**.

---

## 🧰 Technologies Used

| Category | Tools |
|---------|-------|
| Language | Python 3 |
| Data Handling | Pandas, NumPy |
| Visualization | Matplotlib, Seaborn |

---

## 🚀 Features

### 🔹 1. Data Cleaning
- Removed unnecessary columns (e.g., `Unnamed: 0`)  
- Fixed formatting issues in `WklyStudyHours`  
- Verified null values and data types  

### 🔹 2. Exploratory Data Analysis
- **Gender distribution** visualization  
- **Study hour distribution**  
- **Score comparisons** between subjects  
- **Parental education vs performance** trends  

### 🔹 3. Visualizations
Includes:

- Pie charts  
- Bar charts  
- Countplots  
- Grouped mean tables  
- Score distribution curves  

All built using **Matplotlib** and **Seaborn**.

---

## 📊 Key Insights

- Students with **higher weekly study hours** show generally increasing performance.  
- **Parental education** strongly influences Math, Reading, and Writing scores.  
- Gender differences exist in certain subjects but are not extreme.  
- Math, Reading, and Writing scores show **positive correlation**.
